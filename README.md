# Privacy Policies — Murathan Öran

This repository hosts privacy policy pages for iOS apps developed by Murathan Öran.
It is designed to be published via GitHub Pages.

## Setup

1. Push this repository to GitHub.
2. Go to **Settings → Pages** in the repository.
3. Under **Source**, select the **main** branch and the **root (/)** folder.
4. Save. GitHub Pages will publish the site at `https://<your-username>.github.io/privacy-policies/`.

## Technical Notes

- Plain HTML and CSS only.
- No JavaScript.
- No analytics or tracking scripts.
- No external dependencies or CDN links.
- No email address is included in any public policy page.
- Contact for privacy-related inquiries is handled through the App Store listing for each app.
- All policies use system fonts for fast loading with no external font requests.

## Privacy Principles

All apps covered by this repository follow these principles:

- No accounts or user profiles
- No tracking or analytics
- No advertising
- No third-party tracking SDKs
- No sale or sharing of user data
- No developer-side storage of user-created content
- User data stays on the user's device
- Payments handled exclusively by Apple through the App Store
